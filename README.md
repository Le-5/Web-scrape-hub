# WebScrapeHub

A beginner-friendly Flask web scraping dashboard using Requests + BeautifulSoup.

## 1. Install

```bash
python -m venv venv
```

Windows:
```bash
venv\Scripts\activate
```

macOS/Linux:
```bash
source venv/bin/activate
```

Then:

```bash
pip install -r requirements.txt
```

## 2. Run

```bash
python app.py
```

Open:

http://127.0.0.1:5000

## Features

- URL scraping
- Headings
- Paragraphs
- Links
- Images
- HTML tables
- CSV export
- JSON export
- Responsive dashboard UI

## Responsible use

Only scrape content you are allowed to access. Respect a website's Terms of Service, robots.txt, rate limits, copyright, authentication requirements, and technical restrictions. Do not use this project to bypass access controls.
